# Feedback Meetings

Material from research-administrator feedback on the Export to Banner and
RFA Checklist workflows.

## Removed on 2026-10-23

The following were removed from this public repository because they recorded
named university staff or contained real award records:

- `Export To Banner/Export To Banner Workflow Feedback Transcript.vtt` and
  `RFA-Checklist/RFA Checklist Workflow Feedback.vtt` (meeting transcripts)
- `Export To Banner/Email_From_RA.txt`, `Export To Banner/New feedback (8-31)/Email_v1.txt`,
  `Email_v2.txt` and `RFA-Checklist/Email.txt` (emails from research administrators)
- `Export To Banner/New feedback (8-31)/Email_2_attachements/` (two real award
  documents and the workflow's output for each)

The workflow changes they informed are described in each workflow's README and
CHANGELOG. Removing a file here does not remove it from git history; see the
project lead before relying on history for these files.
