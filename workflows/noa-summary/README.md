# NOA Summary (Vandalizer workflow)

New AI4RA-standard rebuild of the public **NOA Summary** workflow. Uploads a
federal **Notice of Award (NoA)** and returns an RA-friendly Markdown **Grant
Award Summary** for a university Office of Sponsored Programs.

**Deliverable — five parts:**
1. Key Personnel & Contacts
2. Grant Summary At-a-Glance
3. Financial & Period of Performance
4. Reporting & Critical Deadlines
5. Key Compliance & Administrative Requirements

Finances and deadlines render as tables; critical restrictions and required
approvals are bolded.

> **v1.0.0 (KB step removed):** the optional Knowledge Base lookup step was removed (MAJOR, 3 steps → 2) — it was inert on import (Vandalizer blanks `kb_uuid`). Extraction tasks now read the uploaded documents directly. Mirrors `rfa-checklist-extraction` v1.0.0. See the [CHANGELOG](CHANGELOG.md).

## Topology

`Extraction` (two parallel prompts: award-basics/financial +
compliance/administrative) → `Consolidation` (five-part Markdown deliverable).
Extraction reads the uploaded NoA directly — there is no knowledge-base step as
of v1.0.0 (the inert `KnowledgeBaseQuery` Step 0 was removed).

- **Source of truth:** [`manifest.yaml`](manifest.yaml). The sibling
  `noa-summary.vandalizer.json` is generated by
  `scripts/build_vandalizer_workflows.py` — do not hand-edit it.
- **Component contract:** [`components/noa-summary-udm`](../../components/noa-summary-udm)
  (JSON extraction contract for tooling).
