# Evals — NOA Summary workflow

Workflow-local evaluation cases live under `cases/`, each with a `metadata.yaml`.
The workflow was validated end-to-end in Vandalizer against a real NIH R25
Notice of Award (see the AI4RA re-validation tracker); the stub case here records
that until an authorized, de-identified award notice and expected deliverable are
committed to `evaluation-data-sets`.
